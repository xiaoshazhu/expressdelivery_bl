# 运单助手 · 飞书多维表格边栏插件

本仓库包含边栏插件前端、Node.js 业务接口及已构建的 `dist/`。插件从当前飞书多维表格识别表和选中记录，使用表格授权码读取字段与运单，并把物流查询结果写回表格。

## 飞书发布与运行地址

- 代码仓库：本仓库；前端入口为 `dist/index.html`。
- 自建服务的边栏地址：`https://express-delivery.anhuishuzhi.com/app/`。
- `server/` 提供授权连接、物流查询、企业信息、额度及支付接口；仅发布静态前端不会启动这些接口。
- 发布构建通过 `.env.production` 将前端 API 请求指向 `https://express-delivery.anhuishuzhi.com`。从 GitHub 源码重新构建或提交 `dist/` 都使用此公网后端；更换后端域名时更新该文件并重新执行 `pnpm build`。

## 使用流程

1. 在飞书多维表格右上角进入「自定义插件 → 获取授权码」，启用并复制当前表格的个人授权码。
2. 打开边栏插件，在「授权码配置」中输入授权码。授权成功后，当前浏览器会保存该表格的授权码供下次自动连接。
3. 在「字段与输出配置」中匹配快递单号和可选的核验手机号字段，按需勾选物流摘要、快递公司、状态、轨迹等结果字段，点击「保存配置并创建字段」。原有的「快递信息」字段继续保存完整结果。
4. 填写运单号后，在「批量查询」中选择当前记录、无结果记录或整列。查询进度和失败原因会显示在弹窗中。同一单号已有结果时跳过；改填新单号后可以查询新运单。
5. 「自动更新」开启后，新增记录或修改输入字段时会查询尚无结果的运单；也可以继续手动批量查询。
6. 试用额度每个企业限领一次；充值、兑换码及退款由后端和管理平台处理。

右上角「使用教程」展示 `public/guide/sidebar-workflow.gif`。授权码弹窗中的四张步骤图也位于 `public/guide/`。

## 本地构建

需要 Node.js 22.12 或更高版本。仓库使用 `pnpm-lock.yaml`：

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm test
```

构建结果在 `dist/`，本仓库已提交该目录用于代码审核和静态部署。若前端与后端部署在不同域名，请在执行 `pnpm build` 前设置 `VITE_API_BASE_URL`。

后端配置放在服务器的 `.env` 中，参考 `.env.example`。不要将真实授权码、物流 AppCode、数据库或支付密钥提交到 GitHub。

## 目录

| 目录 | 内容 |
| --- | --- |
| `src/` | React 边栏界面与飞书前端 SDK 接入 |
| `server/` | Node.js 接口、飞书表格读写、物流与计费 |
| `public/guide/` | 授权步骤图与使用流程 GIF |
| `dist/` | 已构建的边栏静态文件 |
| `tests/` | 服务与接口测试 |
| `docs/` | 功能、开发和部署相关文档 |

完整宝塔部署包在项目交付目录中维护；本仓库中的 `packages.json` 是示例套餐配置，不包含线上 `.env` 或数据库状态。
