# 运单助手 · 飞书多维表格边栏插件 Demo

## 提交平台部署

边栏静态页面入口位于 `dist/index.html`，构建后资源引用使用相对路径。仓库已提交 `dist/`，可将本仓库地址提供给平台部署。修改前端后执行 `pnpm build`，并把更新的 `dist/` 一同提交。

物流查询与计费接口由 `server/` 中的 Node.js 服务提供，静态页面部署不会自动启动该服务。平台将前端与后端部署在不同域名时，构建前设置 `VITE_API_BASE_URL` 为后端公网 HTTPS 地址；后端凭据仅在服务端环境变量中配置，切勿提交 `.env`。

基于飞书团队官方前端模板、官方后端示例和 SDK 构建。采用 **多维表格自定义插件授权码 personalBaseToken**，无需企业自建应用 App ID / App Secret。

## 启动

要求 Node.js 22.12+（本机验证为 24.19.0）及 pnpm。

```sh
pnpm install
pnpm build
pnpm start
```

实际使用入口：在飞书多维表格的「自定义插件 → 新增插件」中填写 http://127.0.0.1:8787/ ，保存并打开。根地址默认运行飞书边栏界面，自动识别当前表格。

独立模拟测试页：打开 http://127.0.0.1:8787/?demo=1 ，点击「进入演示」→「一键查询全部运单」。六条示例预期五条成功，一条货拉拉人工处理。单号以 `0000` 结尾模拟无轨迹。示例单号不能用于真实业务。

开发时两个终端分别运行 `pnpm server` 和 `pnpm dev`，访问 http://127.0.0.1:5173 。Vite 将 `/api` 转发给本地后端。

```sh
pnpm test
pnpm build
```

如果本机没有全局 Node/pnpm，可使用本次环境已有的运行时：

```sh
export PATH=/Users/edy/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin:/Users/edy/.cache/codex-runtimes/codex-primary-runtime/dependencies/bin/fallback:$PATH
pnpm start
```

## 使用真实飞书表格

1. 先在测试用多维表格内开启「自定义插件 → 获取授权码」，复制 personalBaseToken。
2. 在「自定义插件 → 新增插件」填写运行地址并打开，插件自动识别 appToken、tableId 和当前选中行；仅需填写授权码。
3. 点击「授权当前表格」。只有后端通过官方 SDK 读取字段成功，才签发会话。
4. 选择已有两个文本字段；或点击「在当前表创建 / 复用两列」。本操作会修改表结构，但不生成真实快递单号。
5. 可选映射“快递公司”和“核验手机号”文本列；混合承运商批量查询时建议映射。阿里云查询顺丰、中通、跨越时提供完整收/寄件手机号或后四位。
6. 在飞书填入运单，在边栏点击「查询表格中选中的这一行」或「一键查询当前表全部运单」，查询前自动读取最新记录。阿里云模式写入真实状态和最多 50 条轨迹。
7. 新建原生按钮列，并依照工作流文档配置第三列。

飞书授权码不是快递查询凭证，不赋予访问承运商物流接口的能力。真实物流上线前必须完成独立服务商适配。

## 目录

```text
src/                 插件界面、类型、官方 JS SDK 适配示例
server/              HTTP 接口、短期授权会话、官方 Node SDK、模拟及物流供应商适配
tests/               业务及 HTTP 集成测试
docs/                产品、开发、工作流和发布文档
reference/           官方代码与文档快照（与业务代码隔离）
dist/                已构建的网页，pnpm build 生成
```

本工程默认仅监听本机。`NODE_ENV=production` 会主动拒绝启动，避免把当前内存会话和模拟物流误作上架成品。

## 飞书边栏入口（本次修正）

- `/` 是实际边栏插件入口，不再默认展示独立演示工作台。
- 在普通浏览器单独打开 `/` 时只展示如何添加到飞书的说明。
- `/?demo=1` 才是独立模拟测试页。
- 当前表及选中行从飞书 SDK 自动获取；切换表时停止后续请求、清除旧授权，防止错误使用之前的表格配置。已发出的旧表请求仍可能完成。
- 窄屏采用纵向面板，跟随飞书浅色/深色主题。
- Chrome 首次加载本地地址可能要求允许该飞书站点访问本机服务。需用户确认权限。
- localhost/127.0.0.1 仅用于这台电脑开发联调，市场上架仍需公开 HTTPS 服务。
