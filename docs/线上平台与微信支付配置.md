# 线上平台与微信支付配置

## 已接入的边界

边栏插件服务端已经接入参考项目使用的线上平台地址：

- `GET /api/plugin/billing/config`：读取线上套餐和计费配置
- `GET /api/plugin/enterprise/status?tenant_key=...`：查询企业是否登记
- `POST /api/plugin/enterprise/register`：登记企业名称和企业类型

这些接口通过 `PLATFORM_API_URL`、`PLATFORM_API_TOKEN` 和 `PLUGIN_ID` 配置。企业信息会在用户点击充值或领取试用时先查询；已登记企业不会重复弹出企业信息表单。

参考 SDK 不负责插件商品的微信支付下单。订单、二维码、支付查询和支付回调仍由本插件服务端实现，因此本项目的充值弹窗会在插件内显示订单号、套餐、金额和二维码，不再跳转到其他页面。

## 让手机扫码显示安汇数智收款信息

需要从安汇数智微信商户后台取得真实参数并写入本机 `.env`：

```env
WECHAT_APP_ID=微信支付关联的公众号或小程序 AppID
WECHAT_MCH_ID=微信支付商户号
WECHAT_CERT_SERIAL_NO=商户 API 证书序列号
WECHAT_API_V3_KEY=32 位 API v3 密钥
WECHAT_KEY_PATH=D:/path/to/apiclient_key.pem
WECHAT_NOTIFY_URL=https://你的内网穿透域名/api/pay/wechat/notify
MOCK_PAY=false
```

`WECHAT_NOTIFY_URL` 必须是公网 HTTPS 地址，并将请求转发到本机 `http://127.0.0.1:8787/api/pay/wechat/notify`。内网穿透启动后，先访问：

```text
GET https://你的内网穿透域名/api/health
```

确认返回 `wechatPayConfigured: true`，再在边栏点击充值。若为 `false`，弹窗会显示演示二维码；该二维码不能产生真实收款。

## 启动顺序

```powershell
npm run server
npm run dev
```

线上平台配置只由服务端读取，不能把 `PLATFORM_API_TOKEN`、`WECHAT_API_V3_KEY` 或商户私钥写入前端代码。套餐由 `packages.json` 或线上平台计费配置决定；当前本地配置没有年费套餐时，年费页显示为空是配置结果，不是前端跳转问题。

真实支付成功后，插件通过微信支付查询接口确认订单，并把额度写回当前企业。若还需要线上平台统一订单账本，需要平台侧提供订单同步接口或数据库接入信息；参考 SDK 本身没有公开的插件下单接口。
