# 运单助手：真实物流接口与支持范围

核对日期：2026-09-15。当前使用用户指定的阿里云云市场“快证API”快递查询商品。

## 1. 当前接口

| 项目 | 内容 |
|---|---|
| 接口地址 | `https://kzexpress.market.alicloudapi.com/api-mall/api/express/query` |
| 协议 | HTTPS REST API；不是 MCP 协议 |
| 请求方式 | `POST` |
| Content-Type | `application/x-www-form-urlencoded; charset=UTF-8` |
| 当前鉴权 | `Authorization: APPCODE <AppCode>` |
| 返回格式 | JSON |
| 计费主体 | 阿里云云市场对应的已购买商品 |

接口由阿里云API网关鉴权，物流数据由云市场服务商提供。AppCode只能用于它所属的那一个商品，不能把其他快递商品或其他阿里云账号的AppCode混用。

## 2. 请求字段

| 供应商字段 | 飞书来源 | 必填 | 说明 |
|---|---|---|---|
| `expressNo` | 快递单号列 | 是 | 6～32位字母、数字或连字符 |
| `mobile` | 核验手机号列 | 条件必填 | 顺丰、中通、跨越可填写完整 11 位手机号或后四位 |
| `cpCode` | 快递公司列 | 否 | 留空自动识别；非主流和海外快递建议填写商品文档中的编码 |

插件将表格中的单号及可选手机号一起提交阿里云；返回轨迹表示接口查询成功，不代表已经独立证明完整手机号与运单一致。

常用中文别名已经映射：京东、邮政/EMS、安能、跨越、顺丰、中通、圆通、申通、韵达。若服务商调整编码，应以当前商品控制台提供的编码表为准，也可以直接在“快递公司”列填写cpCode。

## 3. 返回并写入飞书的信息

成功响应中的以下字段会转换为统一格式：

| 供应商字段 | 插件用途 |
|---|---|
| `data.cpCode` | 快递公司编码 |
| `data.mailNo` | 运单号 |
| `data.logisticsCompanyName` | 快递公司名称 |
| `data.logisticsStatusDesc` | 当前物流状态 |
| `data.theLastMessage` | 最新物流描述 |
| `data.logisticsTraceDetailList` | 完整轨迹列表 |
| 轨迹的 `time`、`desc`、`areaName` | 节点时间、描述和地点 |

“快递信息”列会写入公司、编码、单号、当前状态、最新信息、查询时间及最多50条轨迹。供应商缺少地点或状态时保持为空，不生成推测数据。

## 4. 支持多少家公司

该商品相关公开页面使用“国内外上千家”和“2500+”等不同宣传口径，不能把最大数字直接当作本插件已验证范围。准确范围分为：

1. **代码范围**：接口接受任意合法cpCode，也支持不传编码自动识别。
2. **商品范围**：以用户购买的阿里云云市场商品详情及其快递编码表为准。
3. **已验证范围**：需要使用真实运单分别测试，目前还没有完成逐家验证。

上线宣传建议写成：“支持所购阿里云云市场快递查询商品已开通的国内外物流公司；具体公司和数据完整度以商品当期编码表为准。”

## 5. 凭证在哪里查看

购买完成后进入：

**阿里云控制台 → 云市场 → 已购买的服务 → 找到当前快递查询商品 → 查看 AppCode/AppKey/AppSecret。**

当前代码采用APPCODE简单认证，因此：

| 配置 | 当前是否使用 | 用途 |
|---|---|---|
| AppCode | **必填** | 放入HTTP Authorization头 |
| AppKey | 暂不使用 | 阿里云API网关签名认证备用 |
| AppSecret | 暂不使用 | 阿里云API网关签名认证备用 |

## 6. 在哪里配置

配置文件为项目根目录 `.env`：

```dotenv
PROVIDER_MODE=aliyun_kzexpress

ALIYUN_EXPRESS_APPCODE=在这里粘贴AppCode
ALIYUN_EXPRESS_APPKEY=可留空
ALIYUN_EXPRESS_APPSECRET=可留空
```

保存后重启：

```sh
pnpm build
pnpm start
```

访问 `http://127.0.0.1:8787/api/health`，应返回：

```json
{
  "ok": true,
  "providerMode": "aliyun_kzexpress",
  "providerConfigured": true,
  "productionReady": false
}
```

飞书边栏顶部随后显示绿色“真实物流已连接：阿里云市场快证快递查询”。

## 7. 错误处理

| 场景 | 插件提示 | 处理方法 |
|---|---|---|
| 未填写AppCode | 真实物流接口未配置 | 填写 `.env` 并重启 |
| HTTP 401/403 Unauthorized | AppCode无效或不属于该商品 | 从当前已购买商品重新复制AppCode |
| HTTP 403 Quota Exhausted | 套餐次数已用完 | 在云市场续购当前商品 |
| HTTP 429 | 请求过于频繁 | 等待后重试、降低批量速度 |
| 手机号查询失败 | mobile错误 | 填写正确的收/寄件手机号或后四位 |
| 暂无轨迹 | 没有查询结果 | 核对单号、cpCode及是否发货 |

成功结果按“cpCode + 单号 + mobile”在单个后端进程缓存30分钟，减少重复扣费。正式多实例部署需改为Redis或数据库缓存。

## 8. 安全和上架要求

- AppCode、AppKey和AppSecret只允许保存在服务器环境变量中，不写入飞书、前端代码、URL或日志。
- `.env` 已被 `.gitignore` 排除，并应保持仅运行账户可读写。
- 真实查询会将单号、cpCode以及查询必需的手机号传给阿里云云市场服务商；隐私政策需要写明第三方接收方和处理目的。
- 阿里云商品购买不等于飞书插件已经达到上架要求；仍需公网HTTPS、多租户隔离、持久任务、额度控制、隐私材料和真实租户验收。

## 9. 其他适配器

原快递100适配器代码暂时保留，便于将来作为备用供应商；当前 `.env` 选择阿里云接口，不会调用快递100。切换供应商必须重启服务。
